SOBRE O PROJETO

Conheça a Wiki.games

Um espaço para reunir informações sobre jogos em uma experiência simples e organizada.

Nosso objetivo

A Wiki.games foi pensada para ajudar os visitantes a pesquisar jogos, conhecer suas histórias, personagens, trailers e atualizações em um só lugar.

Público-alvo

Pessoas que gostam de videogames e querem encontrar informações sobre seus jogos favoritos rapidamente.

Tecnologias utilizadas

HTML para estruturar as páginas, CSS para personalizar o visual, JavaScript para busca e conteúdo dinâmico e Bootstrap para componentes responsivos.
